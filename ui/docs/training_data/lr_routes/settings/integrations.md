# Settings → Integrations

**Route:** `/settings#integrations`
**Who sees it:** any org member; in cloud mode shows an "Enterprise only"
notice instead of connect options (self-hosted-only feature there)

## Purpose

Connect LiveReview to external tools/services beyond git and AI providers
(e.g. chat/notification integrations). Enterprise-gated in cloud mode.

## Key actions

- View available integrations.
- Connect/configure an integration (self-hosted, sufficiently licensed).
