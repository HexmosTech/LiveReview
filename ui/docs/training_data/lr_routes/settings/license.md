# Settings → License

**Route:** `/settings#license`
**Who sees it:** super_admin (cloud); super_admin or org owner (self-hosted)

## Purpose

Manage the self-hosted license key that unlocks Team/Enterprise tier
features (see `internal/license`). Not shown the same way in cloud mode,
where billing/plan is handled via [Plan & Usage](plan-and-usage.md) instead.

## Key actions

- View current license tier and status.
- Add or update a license key.
