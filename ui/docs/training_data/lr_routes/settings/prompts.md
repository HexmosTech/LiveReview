# Settings → Prompts

**Route:** `/settings#prompts`
**Who sees it:** super_admin, or org owner/member

## Purpose

View/manage the AI prompt templates used during review generation (see
`internal/prompts`, PromptBook/LawBook architecture in root `AGENTS.md`).
Lets teams see and, where permitted, customize how reviews are prompted.

## Key actions

- Browse available prompt templates.
- View/edit prompt content where customization is supported.
