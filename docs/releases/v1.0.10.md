# Release v1.0.10

Date: 2026-10-10

## Summary
PR reviews started from LiveReview now get a risk assessment (blast radius) computed on the server, with no CLI needed.

## Install and Update
- Install/update script:
```bash
curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
```
- Pin a specific version:
```bash
curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.0.10
```

## Changes
- **Server-side risk assessment**: PR reviews from GitHub, GitLab, Bitbucket, Gitea and Azure DevOps now get risk scores on each change.
- **Repo cache**: The server keeps a small, recent copy of each reviewed repo to score changes quickly.
- **Repo Cache settings**: Turn it on or off and set the cache size in Settings → Storage → Repo Cache (default 5 GB, minimum 1 GB).
- **Automatic cleanup**: The least recently used repos are removed when the cache is full.
- **Risk assessment on the review page**: The info bar shows the overall risk; expand it to see changes per risk level and the riskiest files.
- **Clear failure reasons**: If risk assessment fails or is skipped, the review page shows why and how to fix it.
- **Storage settings**: Now split into tabs (Blob Storage, Log Compaction, Preloaded Changes Archival, Repo Cache).
- **Review page**: Findings load on their own when a review finishes, and the status updates without a page reload.
- **Review header**: Removed duplicate details and added provider, branch and link icons.
- **Fixes**: Risk badges on comments now match the badge on their change; GitLab and Bitbucket reviews now get risk scores.
- **Security**: Updated Go to 1.26.9 and patched vulnerable dependencies.
