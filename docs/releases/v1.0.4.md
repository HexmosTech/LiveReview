# Release v1.0.4

Date: 2026-09-10

## Summary
- Adds Microsoft Teams bot configuration (single-tenant, live outbound auth), fixes a
  notification-dismissal persistence bug, and reorganizes root-level scripts/config
  files into `scripts/`, `config/`, and `docker/` for a cleaner project layout.
- Patches a dependency-security scan finding (grpc, js-yaml, svgo, colord) flagged by
  the osv-scanner CI check.

## Install and Update
- Install/update script:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
- Pin a specific version:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.0.4

## Changes
- Implement live Microsoft Teams bot configuration and outbound authentication
  (single-tenant).
- Fix notification dismissal persistence.
- Refactor Teams configuration request validation.
- Fix osv-scanner CI failures by bumping vulnerable transitive dependencies:
  google.golang.org/grpc, js-yaml, svgo, colord.
- Reorganize root-level files for a cleaner project layout: move loose scripts,
  Docker Compose files, and config templates into `scripts/`, `docker/`, and
  `config/` (no behavior change; `make dev`/`make -f config/Makefile.test` and
  Docker builds verified working after the moves).
