# Release v1.3.1

Date: 2026-11-21

## Summary
- Blob-storage credentials now live only in the database. `raw-deploy` verifies the `blob_storage` row and prompts to insert it when missing, instead of relying on unused AWS keys in the deploy env.
- `raw-deploy` now installs or upgrades `codebase-memory-mcp` on every deploy, so blast-radius scoring cannot silently run an old binary after a version bump.
- Release tags now require the local security scanners to pass first.

## Install and Update
- Install/update script:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
- Pin a specific version:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.3.1

## Changes
- Removed the unused `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` / `AWS_REGION` entries from the deployment env files. Cloud-storage credentials are configured in `system_settings.blob_storage` (Settings -> Storage) and read fresh on every artifact request.
- The deploy env verifier now rejects those keys outright, so they cannot drift back in.
- Added `livereview storage ensure`: after migrations, `raw-deploy` checks that the storage row exists, is valid, and can write/read/delete a marker object. If the row is missing, it prompts for the values and writes them; otherwise it performs no writes.
- `raw-deploy` (and the staging/backend/low-pricing variants) now run `scripts/install-codebase-memory-mcp.sh`, which upgrades the binary when the installed version differs from the pinned one.
- The gitleaks workflow now authenticates its GitHub API request, fixing intermittent 403 rate-limit failures in the scanner's own setup.
- The MCP integration test now takes its controlled-noop path for both the 402 "insufficient balance" and 429 "low balance" responses, and when `ATLAS_API_KEY` is absent, instead of failing the suite on external billing state.
- Documented that cloud-storage credentials belong in the database, and added the security-scanner gate to the release checklist.
