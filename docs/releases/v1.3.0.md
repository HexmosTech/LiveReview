# Release v1.3.0

Date: 2026-11-20

## Summary
- Adds multi-repo context for blast-radius scoring: link related repositories so a PR's cross-repo API calls (shared HTTP endpoints, events, imports) are taken into account when scoring review priority, instead of only looking at the single repo under review.
- Carries forward the OpenTelemetry dependency bump and the API-key-validation log sanitization fix from the previous patch releases.

## Install and Update
- Install/update script:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
- Pin a specific version:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.3.0

## Changes
- Related Repos: a new "Related Repos" tab under Explore -> Repository -> Settings lets an owner/super-admin link other repositories (any connected provider) to a repository, and remove the link again.
- Blast-radius scoring now folds in cross-repo signal: a new `cross_repo_link` background job runs codebase-memory-mcp's cross-repo-intelligence pass across linked repos and adds a capped "Cross-repo impact" bonus to the affected symbol/hunk, surfaced in the review's blast-radius panel as an "Impacted related repos" chip list.
- Bumped the pinned `codebase-memory-mcp` to v0.12.1 (adds Go/Express route and outbound-call detection, template-literal URL resolution, and OpenAPI route ingestion) and git-lrc's `blastradius` module to v0.1.1.
- Sanitized API keys out of provider error logs surfaced during AI provider key validation.
- Bumped OpenTelemetry modules to v1.47.0 to resolve a dependency security scan finding.
