# Release v1.0.8

Date: 2026-09-30

## Summary
This release brings major reliability improvements to AI interactions, job scheduling, and backend connection handling. It also introduces an Enterprise Enquiry form, a new searchable single-select component, and streamlines the user invitation flow for Cloud instances.

## Install and Update
- Install/update script:
```bash
curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
```
- Pin a specific version:
```bash
curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.0.8
```

## Changes

**✨ New Features & UI Enhancements**
- **Enterprise Enquiry Modal**: Added a new modal to submit company details directly to Discord via a backend webhook ([#120](https://github.com/HexmosTech/LiveReview/pull/120)).
- **Searchable Select**: Upgraded UI primitives to support searchable single-select dropdowns and rich React node labels ([#120](https://github.com/HexmosTech/LiveReview/pull/120)).
- **Comment Numbering**: "Copy all visible issues" in the diff viewer now properly prefixes copied comments with sequential numbers (e.g., `1. path/to/file:line ...`) ([#122](https://github.com/HexmosTech/LiveReview/pull/122)).
- **Chat UI Layout**: Aligned avatars inline, added blockquote parsing with error callouts, and introduced configuration shortcut banners in the chat UI ([#124](https://github.com/HexmosTech/LiveReview/pull/124)).

**🛠️ Reliability & AI Improvements**
- **Robust AI Error Handling**: The MCP agent now catches provider authentication and model errors, injects friendly recovery messages, and halts execution gracefully ([#124](https://github.com/HexmosTech/LiveReview/pull/124)).
- **Connection Timeout Resilience**: Increased the chat API timeout to 300s. Introduced `context.WithoutCancel` so LLM and DB processing continues even if the HTTP connection is dropped, and added frontend polling to gracefully retrieve responses on 503/504 errors ([#127](https://github.com/HexmosTech/LiveReview/pull/127)).
- **Diff Confidence Parsing**: Improved the robustness of diff review score decoding by handling mismatched JSON key capitalization and type-switching ([#124](https://github.com/HexmosTech/LiveReview/pull/124)).
- **Hallucination Fix**: Prevented the Helper model from hallucinating dummy comments when the leader model generates 0 issues ([#122](https://github.com/HexmosTech/LiveReview/pull/122)).

**⚙️ Backend & Infrastructure**
- **Cron Job Memory Leak Fix**: Migrated archival scheduling from a River periodic scheduler to a safer in-memory cron runner, resolving resource leaks and concurrency race conditions in `preloaded_changes_archival.go` ([#122](https://github.com/HexmosTech/LiveReview/pull/122), [#124](https://github.com/HexmosTech/LiveReview/pull/124)).
- **Database Bloat Reduction**: Slashed the retention period for discarded background jobs from 30 days to 7 days, significantly reducing DB size (e.g., clearing ~710K discarded `repo_pr_sync` jobs) ([#127](https://github.com/HexmosTech/LiveReview/pull/127)).
- **Cloud Invitation Flow**: Fixed an issue where Cloud mode incorrectly demanded SMTP configuration before sending user invites. Cloud instances now correctly use the Parse `userInvitation` function and bypass the SMTP prerequisite UI.
