# Release v1.0.9

Date: 2026-10-05

## Summary
The blast-radius diff viewer now blends each finding's severity (critical/warning/info) into the hunk risk score, so a critical security bug outranks a trivial typo even in a lower-blast-radius change.

## Install and Update
- Install/update script:
```bash
curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
```
- Pin a specific version:
```bash
curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.0.9
```

## Changes
- **Severity-aware ordering**: Blast-radius hunks are now ordered by a score that blends the structural blast-radius/review-priority score (90%) with the most severe LLM finding on the hunk (10%; critical=100, warning=25, info=5).
- **Finding Severity breakdown**: The "why this score" panel now includes a Finding Severity dimension alongside Blast Radius and Review Priority, plus a color-coded severity chip (Critical/Warning/Info).
- **Math Mode**: Math Mode now walks through the severity step and ends on the blended final score, so the headline number and the sort order stay consistent.
- Severity only applies where the review already carries finding-severity data; webhook- and web-UI-triggered reviews without it are unaffected.
