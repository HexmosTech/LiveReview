# Release v1.2.2

Date: 2026-11-06

## Summary

A small maintenance release: two known-vulnerable dependencies are updated to
patched versions, and the GitHub sign-in flow now carries better internal
visibility for monitoring signup activity. No user-facing behavior changes.

## Install and Update
- Install/update script:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
- Pin a specific version:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.2.2

## Changes

### Dependency security updates

Updated `github.com/andybalholm/brotli` and `github.com/klauspost/compress`
to their latest patched versions, resolving two vulnerabilities flagged by
automated dependency scanning.

### Internal: GitHub sign-in monitoring

Added internal, non-customer-facing visibility improvements around new
organizations connecting GitHub and submitting their first review, and
around traffic through the "Continue with GitHub" sign-in flow.

## Breaking Changes
- None.

## Verification
- livereview --version
- lrops.sh --show-latest-version

## Known Issues
- Three additional dependency vulnerabilities flagged by govulncheck
  (`github.com/crewjam/saml`, two in `github.com/labstack/echo/v4`) have no
  patched version available upstream yet for the major version we use (the
  echo fixes ship only in echo v5, a breaking upgrade). Tracked for a future
  release once a non-breaking fix is available.
