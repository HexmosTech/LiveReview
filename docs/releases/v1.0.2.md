# Release v1.0.2

Date: 2026-09-06

## Summary
- CI/CD Rulesets feature: new backend + UI to define org-scoped jq-expression rules against review findings, exposed via a /ci-rulesets/:id/evaluate endpoint CI pipelines can gate on by HTTP status code (200 allow / 422 block), plus DB migration, tests, and a dedicated CiRulesets UI section.
- Makefile/CI-enforcement cleanup: resolved a stash-pop conflict, dropped an obsolete training-data-check block with no live references.
- Self-hosted backup + local Postgres 18 fixes: lrops.sh backup/restore now captures app data (blob store) alongside the DB with compression and path-traversal validation, plus custom-named-backup listing fixes; pgctl.sh (local dev Postgres) bumped to Postgres 18 with the matching volume-mount-path fix.  

## Install and Update
- Install/update script:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
- Pin a specific version:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.0.2
