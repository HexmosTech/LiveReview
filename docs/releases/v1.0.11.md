# Release v1.0.11

Date: 2026-10-16

## Summary
Risk-based auto-approve: LiveReview can now approve low-risk pull requests on its own, and every new PR gets "Start a review" links in its description.

## Install and Update
- Install/update script:
```bash
curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
```
- Pin a specific version:
```bash
curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.0.11
```

## Changes
- **PR review links**: New PRs on GitHub, GitLab, Gitea, Bitbucket and Azure DevOps get **Start a review** and **Review history** links in their description.
- **Auto-approve policy**: A review started from that link runs 5 checks (author eligibility, static rules, risk score, AI classification, final decision), then approves the PR or marks it "Not approved".
- **Decisions table**: The PR description lists the last 10 decisions with the reason for each, including force approvals and repo mode overrides.
- **Policy settings**: Set an org policy in Settings → Auto Approve, and override it per repo (Inherit, Custom, Always approve, Never approve). The risk threshold has Conservative, Balanced and Aggressive presets, or a custom value.
- **Author levels**: Give each user a review level and link their Git username or email, so the policy knows who wrote the PR.
- **Force approve**: Owners, admins and senior reviewers can approve a blocked PR with a reason. It is posted to the PR and kept in the audit log.
- **Production feedback**: Mark a review as reverted, an incident, or confirmed safe, from the review page or from CI through the API. The risk model learns from it.
- **Auto Approve report**: Reports → Auto Approve shows score distribution, decisions and how often approvals turned out wrong.
- **Review page**: New Auto Approve tab and an Auto-approve status next to Risk assessment.
- **Chat**: Clearer error messages and recovery when the AI provider fails.
- **Fixes**: Deleting a connector no longer fails because of review commit history; saving a repo's auto-approve mode no longer fails; Bitbucket token hints list the write scopes needed.
- **Navbar**: Reordered the top bar items and moved the org selector next to logout.

## Breaking Changes
- None. Auto-approve is off until an org creates a policy. New PRs on connected repos now get a LiveReview section in their description (needs the public URL set in settings).
