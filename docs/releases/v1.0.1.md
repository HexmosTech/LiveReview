# Release v1.0.1

Date: 2026-09-04

## Summary
- Self-hosted improvements: org owner settings access, quota refinements, and lrops reverse proxy/SSL setup fixes.

## Install and Update
- Install/update script:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
- Pin a specific version:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.0.1

## Changes
- Enabled Org Owner access to self-hosted settings
- Refined self-hosted quota
- Fixed reverse proxy and SSL setup in lrops: added `doctor` command, proxy selection during SSL setup, and applied nginx tuning to caddy/apache templates.
- Fixed zero-connector orgs returning null instead of an empty array.

## Breaking Changes
- None.
