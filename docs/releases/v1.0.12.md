# Release v1.0.12

Date: 2026-10-17

## Summary
Auto-approve is now on by default for every organization and runs on every manual PR review. The New Review page is redesigned, and several fixes found while testing v1.0.11 are included.

## Install and Update
- Install/update script:
```bash
curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
```
- Pin a specific version:
```bash
curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.0.12
```

## Changes
- **Auto-approve on by default**: Every organization, existing and new, now gets a default auto-approve policy (Conservative threshold, LLM confidence 8). Owners can change it in Settings → Auto Approve Policies.
- **Policy check on manual reviews**: Reviews started from New Review (pasted PR URL) or Trigger Review in Explore → Merge Requests now run the auto-approve check and show the Auto Approve tab, just like the PR description link.
- **PR description**: Under the decisions table, a new line links to "Customize risk-based approval policy for this repository or your organization".
- **New Review page**: Search open PRs by repository, title or author and start a review in one click, or paste a PR URL. The page also lists the other ways to review: on the PR, pre-commit CLI, IDE / MCP, CI/CD & API, chatbot and scheduled.
- **Explore → Merge Requests**: Trigger Review now opens the new review page directly.
- **Back buttons**: One consistent back arrow, at the top left of every page that has one.
- **Fixes**: Deleting a Git connector no longer fails when one of its repos has an auto-approve override; the Auto Approve report no longer crashes when an org has no decisions or outcomes yet.
- **Security**: Updated `kin-openapi` to v0.151.0 to clear six published advisories.

## Breaking Changes
- Auto-approve is now on for every organization by default. Reviews started from the PR description link, New Review or Explore → Merge Requests will post an approve or block verdict on the PR. To opt a repository out, set its Auto Approve mode to **Never approve** in Explore → Repositories → repository settings.

## Verification
```bash
livereview --version
lrops.sh --show-latest-version
```

## Known Issues
- When the same repository is connected in more than one LiveReview organization, the PR description links point to whichever organization updated the PR last.
- Gitea has not been tested end to end with auto-approve yet.
