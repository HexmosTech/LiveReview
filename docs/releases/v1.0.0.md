# Release v1.0.0

Date: 2026-09-02

## Summary
- Introduces Livi AI Assistant v2, an upgraded multi-branch architecture covering Product Guidance, Actions (triggering code reviews and inspecting review details), and Historical Analytics with dynamic Vega-Lite chart visualizations.

## Install and Update
- Install/update script:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
- Pin a specific version:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.0.0

## Changes
- Added intent classification with multi-branch routing (product_guidance, action, analytics), so every prompt is routed to the right execution path before token allocation.
- Added `dbctx`: a high-performance database context indexing tool that generates schema-aware query contexts and sample SQL patterns for accurate text-to-SQL synthesis.
- Integrated `alaws`: system prompts are now dynamically assembled from versioned LawBooks (`internal/mcpagent/alaws_livi/`) using `{{ref:}}` templates for consistent policy enforcement and to prevent prompt drift.
- Unified no-data analytics guidance: replaced raw query dumps on empty/single-row results with friendly guidance and suggested Product Guidance question cards.
- Fixed Vega-Lite chart rendering: optimized InteractiveChart container sizing for instant, responsive SVG mounting and correct scaling on dark-mode cards.
