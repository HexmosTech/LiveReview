# Release v0.0.52

Date: 2026-09-02

## Summary
- This release includes various fixes to the Livi Chatbot,including supporting more queries, UI etc.

## Install and Update
- Install/update script:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
- Pin a specific version:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v0.0.52

## Changes
- Various bug fixes and improvements in the Livi Chatbot
- Improved Chat Response format, markdown support
- Added more MCP tools for listing repository, PR and fetching org member details.
