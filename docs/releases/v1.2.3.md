# Release v1.2.3

Date: 2026-11-06

## Summary

A maintenance release: three known-vulnerable dependencies are updated to
patched versions (brotli, compress, and SAML), and internal CI security
scanning is hardened to stay reliable going forward. No user-facing
behavior changes.

## Install and Update
- Install/update script:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash
- Pin a specific version:
  - curl -fsSL https://raw.githubusercontent.com/HexmosTech/LiveReview/master/lrops.sh | bash -s -- --version=v1.2.3

## Changes

### Dependency security updates

Updated `github.com/andybalholm/brotli`, `github.com/klauspost/compress`,
and `github.com/crewjam/saml` to their latest patched versions, resolving
vulnerabilities flagged by automated dependency scanning (including a
nil-pointer panic in SAML response validation).

### Internal: GitHub sign-in monitoring

Added internal, non-customer-facing visibility improvements around new
organizations connecting GitHub and submitting their first review, and
around traffic through the "Continue with GitHub" sign-in flow.

### Internal: CI hardening

Our automated vulnerability scanning (`govulncheck`) now has a documented
waiver mechanism for the rare case where a flagged issue has no non-breaking
upstream fix yet, instead of a flat pass/fail with no record of why. This
keeps our security gate accurate without silently masking genuinely new
issues.

## Breaking Changes
- None.

## Verification
- livereview --version
- lrops.sh --show-latest-version

## Known Issues
- Two dependency vulnerabilities in `github.com/labstack/echo/v4` have no
  patched version available in the v4 line we use (fixes ship only in echo
  v5, a breaking upgrade we haven't undertaken). Both are already mitigated
  in practice by our existing reverse-proxy IP-extraction configuration, and
  are tracked for a future release once a non-breaking fix path exists.
