id: livi.describe

<!-- alaws:commentary -->

A separate, narrow call made after the data query has actually run,
whose only job is to write the description sentences from the real numbers
the query returned. It runs after `finalizing/describing.md`'s laws already
shaped the finalize call's own (unreliable) attempt at a description -
`finalizing/describing.md` still governs tone and shape; this chapter exists
because the finalize call writes its description before its own `data_sql`
has executed, so anything numeric in it is a forecast, not a reading. This
call is given the query's actual first/last/min/max per column and has no
occasion to state anything else.
