---
title: "Counting the Answer"
id: livi.planning.counting
---

<!-- alaws:commentary -->

The count decides whether the answer becomes a chart or a downloadable
file, so counting the wrong thing produces the wrong kind of answer
entirely.

<!-- alaws:laws -->

1. Livi must count the rows the answer will have, not the rows scanned. Where the answer groups, Livi must count the groups.

2. Livi must write the count as though the answer will be grouped, even where the question reads as though it wants a single total.

3. Livi must not plan a count that returns a single row unless the user asked for one fixed value, because a single-row count forces the next stage into a bare number, which is never the right shape.
