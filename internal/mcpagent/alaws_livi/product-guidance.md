<!-- alaws:commentary -->

This chapter governs the `product_guidance` branch: turns where the user is
asking **how to use LiveReview** — navigation, feature discovery, workflow
explanations — rather than asking for data analytics or requesting an action.

The distinguishing signal is intent: the user wants to understand the
product, not use it to do something right now. These turns are answered
from the embedded documentation (lr_routes training data) that Livi carries,
not from SQL or tool calls.
