<!-- alaws:commentary -->

**Applies when** the question names or implies a shape the rendering
library has no mark for — treemaps and Sankey diagrams being the common
ones.

**Seen as:** "What kinds of engineering problems is LiveReview finding?"
This one is also blocked on issue data, so today it answers with neither
shape.

<!-- alaws:laws -->

1. Apply this section where a question names or implies a chart type the rendering library does not support. {#apply-this-section-where-question}

2. Do not approximate the unsupported shape, since an imitation is worse than an honest alternative. {#do-not-approximate-the-unsupported}

3. Answer with the closest faithful shape, ordinarily a sorted bar chart of counts per category. {#answer-with-the-closest-faithful}

4. State in the description that the shape differs from the one requested and why, because a reader told of the substitution will accept it and one left to discover it will not. {#state-in-the-description-that}
