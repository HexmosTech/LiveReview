# git-lrc Docs

Free, unlimited AI code reviews that run on commit.

GenAI can generate large code changes quickly. It can also silently remove logic, relax constraints, introduce expensive operations, and change behavior. git-lrc adds a review checkpoint at commit-time, when responsibility is explicit.

## Why git-lrc exists

AI-assisted coding increased velocity, but careful review quality dropped, and regressions appeared later than they should.

git-lrc structurally encourages review at commit-time while keeping developers in control with explicit choices: review, vouch, or skip.
