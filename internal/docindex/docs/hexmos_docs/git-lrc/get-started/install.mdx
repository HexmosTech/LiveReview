# Install

## Linux and macOS

```bash
curl -L https://hexmos.com/ipm-install | bash && ipm i HexmosTech/git-lrc
```

## Windows (PowerShell)

```powershell
iwr https://hexmos.com/ipm-install-ps | iex; ipm i HexmosTech/git-lrc
```

## One-Time Setup

```bash
git lrc setup
```

Setup opens browser-based steps:

1. Authenticate for LiveReview coordinator access
2. Add Gemini API key (or later configure other connectors)

After setup, commit-time review is active across repositories on the machine.

## Verify Installation

```bash
lrc version
lrc hooks status
```

## Optional Global Hook Install

```bash
lrc hooks install
```
