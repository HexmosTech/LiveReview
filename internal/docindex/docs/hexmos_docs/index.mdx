## LiveReview MCP & API

Take LiveReview further with programmatic access and deep integrations:

- **[MCP Server](/livereview/docs/livereview/mcp/)** — Connect LiveReview to Claude Desktop, GitHub Copilot, and any MCP-compatible host. Use built-in tools to query reviews, manage learnings, and automate workflows.
- **[API Reference](/livereview/docs/livereview/api/)** — Full REST API covering reviews, connectors, AI providers, organizations, billing, learnings, prompts, and diff review. Build custom tooling, dashboards, and CI/CD integrations around the LiveReview engine.

Both expose the same review engine that powers git-lrc and claude-lrc, giving you full control over the review pipeline.
