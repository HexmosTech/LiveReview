## Prerequisite

There is a prerequisite for creating a code review. There must at least be *1 Git Provider* and *1 AI Backend* already connected.

If you're starting out for the first time with LiveReview, the first two items must be ticked off in this panel in the homepage:

<img width="850" height="250" alt="image" src="https://github.com/user-attachments/assets/9ce7849a-397f-46da-a770-afe7bc1672f5" />


## Creating a review

Once you have at least 1 git provider and 1 AI provider, click "New Review"

<img width="950" height="435" alt="image" src="https://github.com/user-attachments/assets/ad527783-21ba-46d3-b743-5c3bbc135fba" />

In the "New Review" page - you can take an MR/PR link and click "Trigger Review". Give it a few moments - you should see comments in the thread:
