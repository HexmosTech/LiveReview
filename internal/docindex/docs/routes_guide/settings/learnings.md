# Settings → Learnings

**Route:** `/settings#learnings`
**Who sees it:** any org member

## Purpose

Manage the org's "learnings" — team-specific rules/conventions/preferences
that LiveReview's AI review pipeline takes into account (see
`internal/learnings`). Lets teams teach the reviewer their own standards
(e.g. "don't flag X", "always require Y") beyond generic best practices.

## Key actions

- View existing learnings.
- Add a new learning (owner-level action).
- Edit or delete a learning (owner-level action).
