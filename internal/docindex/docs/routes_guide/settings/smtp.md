# Settings → SMTP

**Route:** `/settings#smtp`
**Who sees it:** super_admin, self-hosted deployments only (hidden in cloud mode)

## Purpose

Configure the outbound email (SMTP) server self-hosted instances use to
send notification emails (invites, alerts, etc.).

## Key actions

- Set SMTP host, port, credentials, and sender address.
- Send a test email to verify configuration.
