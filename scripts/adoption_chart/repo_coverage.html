Average coverage: 2.92 reviews per PR across 2 repos with PR data.
Y axis is LOC reviewed, not a reviewed/changed ratio - total changed LOC per PR (git-host diff stats) isn't tracked in this schema.
Query used 
SELECT rp.name AS repository,
           count(DISTINCT pr.id) AS prs,
           count(DISTINCT r.id) AS reviews,
           count(DISTINCT r.author_username) AS engineers,
           coalesce(sum(l.billable_loc), 0) AS loc
    FROM repositories rp
    LEFT JOIN pull_requests pr ON pr.repository_id = rp.id
      AND pr.provider_created_at >= CURRENT_DATE - INTERVAL '90 days'
    LEFT JOIN reviews r ON r.repository = rp.name AND r.org_id = 151
      AND COALESCE(r.completed_at, r.created_at) >= CURRENT_DATE - INTERVAL '90 days'
    LEFT JOIN loc_usage_ledger l ON l.review_id = r.id AND l.status = 'accounted'
    WHERE rp.org_id = 151
    GROUP BY 1
    HAVING count(DISTINCT r.id) > 0
    ORDER BY 3 DESC;
