Top 3 repositories account for 69% of all LOC reviewed (43 repos total).
Query used 
SELECT r.repository, sum(l.billable_loc) AS loc
    FROM loc_usage_ledger l
    JOIN reviews r ON r.id = l.review_id
    WHERE l.org_id = 151 AND l.status = 'accounted'
      AND l.accounted_at >= CURRENT_DATE - INTERVAL '90 days'
    GROUP BY 1
    ORDER BY 2 DESC;
